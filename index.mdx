Alpha Insight's MCP server and API give your AI tools read-only access to Hyperliquid wallet
analytics, copy-trade status, and live market data. Connect once with an API key or with OAuth 2.1,
then call 14 tools from Claude, Cursor, VS Code, or plain HTTP. Every tool is read-only — none of
them places, changes, or cancels an order.

<Card title="First call in 2 minutes" icon="rocket" href="/quickstart">
  Create a key, connect Claude Code, and run your first tool.
</Card>

## Two ways to sign in

<CardGroup cols={2}>
  <Card title="API key" icon="key" href="/auth/api-keys">
    Create a key in **Settings → API Keys**, then send it as `Authorization: Bearer ak_live_…`.
    Works with any MCP client and with plain HTTP.
  </Card>
  <Card title="OAuth 2.1" icon="shield-check" href="/auth/oauth">
    Add Alpha Insight as a custom connector in claude.ai and approve it on the consent screen. No
    key to copy.
  </Card>
</CardGroup>

## What you can call

<CardGroup cols={2}>
  <Card title="Wallet analytics" icon="chart-line" href="/tools/overview">
    Wallet performance, portfolio summaries, alpha search, watchlists, and copy-trade status.
  </Card>
  <Card title="Market data" icon="book" href="/tools/overview">
    Live snapshots, order books, recent trades, candles, funding, and the market list.
  </Card>
</CardGroup>

Both surfaces speak the same tools: MCP clients use the protocol directly, and plain HTTP uses
JSON-RPC 2.0 `tools/list` and `tools/call`. Start with the
[quickstart](/quickstart), or read the [tools overview](/tools/overview).
