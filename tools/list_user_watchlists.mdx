---
title: "list_user_watchlists"
description: "Your saved watchlists with a lightweight stats rollup."
---

Lists the watchlists on the signed-in account, each with a summary of the wallets it holds. Returns
the caller's own lists only.

## Inputs

None. The tool takes no parameters.

## Output

| Field | Type | Description |
| --- | --- | --- |
| `summary` | string | One-line summary (≤100 characters). |
| `watchlists` | object[] | Your watchlists, newest first. |
| `truncated` | boolean | `true` when you have more watchlists than are shown. |

Each entry in `watchlists` has: `id` (UUID), `name`, `wallet_count`, and `summary` — an object with
`total_pnl`, `win_rate`, and `total_trades`, or `null` when no stats are available.

## Example call

```bash
curl -sS https://api.alphainsight.xyz/mcp \
  -H "Authorization: Bearer ak_live_your_key_here" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "list_user_watchlists",
      "arguments": {}
    }
  }'
```

Trimmed example response (values are examples):

```json
{
  "summary": "2 watchlists · 18 unique wallets",
  "watchlists": [
    {
      "id": "3f2a1c4e-9b7d-4a2f-8c1e-2d5b7a9f0c33",
      "name": "<data>High-conviction perps</data>",
      "wallet_count": 12,
      "summary": { "total_pnl": 418220.5, "win_rate": 58.9, "total_trades": 2840 }
    },
    {
      "id": "7c8e2d10-4f5a-4b3c-9e21-6a0d3f8b1a44",
      "name": "<data>Watching</data>",
      "wallet_count": 6,
      "summary": null
    }
  ],
  "truncated": false
}
```

## Limits and caveats

- Shows at most 50 watchlists per call. When there are more, `truncated` is `true` and the summary
  says so.
- The stats rollup is best-effort: if the underlying stats lookup is unavailable, every watchlist's
  `summary` comes back as `null` and the list itself still returns.
- Wallet counts are the true counts for each watchlist even when the per-wallet stats are missing.
- Watchlist names you typed come back wrapped in `<data>` tags, so an assistant treats them as
  text, not instructions.
