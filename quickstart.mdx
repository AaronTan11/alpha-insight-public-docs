title: "Quickstart"
description: "Create a key, connect Claude Code, and run your first tool."
---

This takes about two minutes. You need an Alpha Insight account and
[Claude Code](https://docs.anthropic.com/en/docs/claude-code) installed.

<Steps>
  <Step title="Create an API key">
    Go to [alphainsight.xyz/settings?tab=api-keys](https://alphainsight.xyz/settings?tab=api-keys)
    and click **Generate Key**.

    The full key is shown once. Copy it now — you cannot see it again. It starts with `ak_live_`.

    <Warning>
      Treat the key like a password. Don't commit it, and don't put it in a URL — request paths are
      logged. See [API keys](/auth/api-keys) for creating and revoking keys.
    </Warning>

    <Note>
      The **API Keys** screen is part of a paid plan. On a free account, connect with OAuth instead —
      see [claude.ai](/connect/claude).
    </Note>
  </Step>
  <Step title="Connect Claude Code">
    Run this once, replacing the key with the one you just copied:

    ```bash
    claude mcp add --transport http alpha-insight https://api.alphainsight.xyz/mcp --header "Authorization: Bearer ak_live_your_key_here"
    ```

    Claude Code prints `Added …` when the configuration is written. Check the connection with:

    ```bash
    claude mcp list
    ```

    A healthy entry reads `✔ Connected`. To sign in with OAuth instead of a key, omit the
    `--header` part and run `/mcp` inside Claude Code — see
    [Claude Code](/connect/claude-code).
  </Step>
  <Step title="Run your first tool">
    In Claude Code, ask:

    ```text
    Use list_markets to show me the perps on the main exchange.
    ```

    Claude Code calls `list_markets` on the server and shows the result.
  </Step>
  <Step title="See a result">
    `list_markets` returns a one-line summary plus the full JSON. A trimmed example:

    ```json
    {
      "summary": "212 perps across 9 dex(es)",
      "dexes": [
        { "name": "main", "full_name": "Hyperliquid main exchange" }
      ],
      "perps": [
        { "coin": "BTC", "dex": "main", "max_leverage": 40, "sz_decimals": 5, "delisted": false },
        { "coin": "ETH", "dex": "main", "max_leverage": 25, "sz_decimals": 4, "delisted": false }
      ],
      "spot_tokens": []
    }
    ```

    The numbers above are examples. Your call returns live data from Hyperliquid.
  </Step>
</Steps>
